# Phase 2 — Spatial design and expressive motion

Intent: noticeably dimensional, warm tactile examples, with the preserved mascot and photographs, without launching or rewriting the product website.

Approaches considered: Motion/GSAP timelines (unnecessary dependency for bounded transforms); true3D geometry (no approved3D asset/value); existing pointer controller plus native observation/CSS (selected under the standing no-questions approval). No new dependencies or articulated/distorted mascot. The implementer owns these choices.

Dedicated route `/design-system/motion`, linked from the guide. It demonstrates all ten requested areas in one paced sequence: rigid-frame animated mascot, three illustrative service-card patterns, tactile buttons, sticky glass navigation, once-per-enabled-session scroll reveals/images, two decorative parallax planes, cursor-responsive shadows, restrained glow, explicit token table and reduced alternatives. No new service facts, contact destination, booking, persistence, publication or home change.

Reuse SpatialCard/SpatialLayer, Card, BrandPhoto, GlassSurface, SiteHeader, existing glow/actions. Pointer targets remain±4deg/lift4px, perspective1000px, planes12/24px, scale1.01/.99. Add scoped spring-inspired cubic easing and300ms reset (not a physical spring simulation), section entrance550ms, hello600ms, rigid mascot rotation±2deg, parallax back−12/front20px and shadow travel6px. Dynamic shadows stay warm; directional light remains behind text. Existing shared150/250/400ms roles remain unchanged outside this route.

Controls: Enable spatial motion initiallyfalse; Simulate reduced motion initiallyfalse. Effective pause is !enabled||simulated. OS reduction always wins. No auto ambient loops: hello is a finite explicit animation and floating stays hover-driven. All essential content renders visible on SSR/noJS and controls only enhance. Touch disables cursor tracking and decorative scroll parallax; intersection reveals remain short and optional. Focus cancels reveal/parallax movement; header anchors/focus targets reserve wrapped-header clearance.

ScrollScene wraps server-rendered children. One IntersectionObserver handles root visibility and marked reveal elements. Reveal markers add a finite CSS entrance only when intersecting; content is not pre-hidden. One passive scroll/resize subscriber schedules at most one RAF, reads one untransformed root rect, writes one clamped progress custom property. Skip parallax while offscreen, coarse, reduced, focused or document-hidden. Cleanup disconnects observers/listeners, cancels queued frames and removes styles/animation markers. Missing IntersectionObserver yields static content. Decorative parallax planes use data attributes and stay outside the accessibility tree.

AnimatedMascot reuses SpatialCard and original MascotSignature; pointer tracking moves its rigid frame and decorative layers. A native Say hello button restarts one bounded greeting; no facial/head articulation or whole-image warping. Mark transforms and panels as decorative where appropriate. Native CTA links own activation; no extra Card tab stops.

Acceptance: meaningful observer/RAF lifecycle tests, original pointer tests, full required gates; real browser verifies pointer tilt/reset/dynamic shadow, finite mascot hello, staggered reveals, clamped parallax, offscreen/pause/OS/local reduction, sticky navigation/focus, touch/noJS, four widths, no page errors; independent final source review. Local performance evidence is structural/bundle/browser, not a production Core Web Vitals result.
